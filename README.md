# Goalbreaker site

Static pages for the Goalbreaker mobile game, served by GitHub Pages:

- `privacy.html` — privacy policy (English)
- `gizlilik.html` — gizlilik politikası (Türkçe)
- `support.html` — support and contact
- `index.html` — landing page

Plain HTML and CSS, no build step. Edit a page and push to `main`.
